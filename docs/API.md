# API Reference

Base URL during development: `http://localhost:4000/api`. The frontend dev server also forwards `/api` to this address.

All request and response bodies are JSON. CORS is enabled.

## The todo object

| Field | Type | Notes |
|---|---|---|
| `id` | string | Unique id (UUID), generated by the server |
| `title` | string | 1 to 200 characters |
| `description` | string | Up to 2000 characters; `""` when empty |
| `priority` | string | `low`, `medium` or `high` |
| `dueDate` | string or null | `YYYY-MM-DD`, or `null` |
| `completed` | boolean | |
| `createdAt` | string | ISO 8601 timestamp |
| `updatedAt` | string | ISO 8601 timestamp; changes on every update |

Example:

```json
{
  "id": "238faec6-c7b0-4f46-b02d-fa697cb557e9",
  "title": "Buy milk",
  "description": "",
  "priority": "high",
  "dueDate": "2026-12-01",
  "completed": false,
  "createdAt": "2026-11-26T11:44:37.843Z",
  "updatedAt": "2026-11-26T11:44:37.843Z"
}
```

## Endpoints

| Method | Path | Description | Success |
|---|---|---|---|
| GET | `/api/health` | Health check | 200 |
| GET | `/api/todos` | List todos (with optional filters) | 200 |
| GET | `/api/todos/:id` | Get one todo | 200 |
| POST | `/api/todos` | Create a todo | 201 |
| PATCH | `/api/todos/:id` | Update a todo (only the fields you send) | 200 |
| PUT | `/api/todos/:id` | Same behaviour as PATCH | 200 |
| DELETE | `/api/todos/:id` | Delete a todo | 204 (no body) |

### GET /api/health

Returns `{ "status": "ok" }`.

### GET /api/todos

Returns an array of todos. All query parameters are optional.

| Parameter | Values | Default | Effect |
|---|---|---|---|
| `status` | `all`, `active`, `completed` | `all` | Filter by completion |
| `priority` | `low`, `medium`, `high` | none | Filter by priority |
| `search` | any text | none | Case-insensitive match on title and description |
| `sort` | `createdAt`, `dueDate`, `priority`, `title` | `createdAt` | Sort field |
| `order` | `asc`, `desc` | `desc` for `createdAt`, otherwise `asc` | Sort direction |

Sorting notes:
- `priority` ranks low < medium < high.
- `dueDate` always places todos without a due date last, in either direction.
- `title` ignores upper/lower case.

An invalid value for `status`, `priority`, `sort` or `order` returns 400.

Example: `GET /api/todos?status=active&priority=high&sort=dueDate`

### GET /api/todos/:id

Returns the todo, or 404 if the id does not exist.

### POST /api/todos

Request body:

```json
{ "title": "Buy milk", "description": "2 litres", "priority": "high", "dueDate": "2026-12-01" }
```

Only `title` is required. Defaults: `description` is `""`, `priority` is `medium`, `dueDate` is `null`, `completed` is `false`. The response has status 201 and a `Location` header of `/api/todos/<id>`.

### PATCH /api/todos/:id (and PUT)

Send any subset of `title`, `description`, `priority`, `dueDate` and `completed`. Fields you leave out are unchanged. Set `dueDate` to `null` to clear it. The `id`, `createdAt` and any unknown fields in the body are ignored. An empty body returns 400. An unknown id returns 404.

### DELETE /api/todos/:id

Returns 204 with no body, or 404 if the id does not exist.

## Validation rules

| Field | Rule |
|---|---|
| `title` | Required on create. Non-empty string after trimming, at most 200 characters. |
| `description` | String, at most 2000 characters. |
| `priority` | One of `low`, `medium`, `high`. |
| `dueDate` | A real calendar date as `YYYY-MM-DD` (for example, `2026-02-30` is rejected), or `null` / `""` to clear. |
| `completed` | Boolean. |
| Request body | Must be a JSON object. |

## Errors

All errors are JSON.

| Status | When | Body |
|---|---|---|
| 400 | Validation failed | `{ "error": "Validation failed", "details": ["..."] }` |
| 400 | Invalid query parameter | `{ "error": "Invalid query parameters", "details": ["..."] }` |
| 400 | Malformed JSON body | `{ "error": "Malformed JSON in request body" }` |
| 404 | Unknown todo id | `{ "error": "Todo not found" }` |
| 404 | Unknown route | `{ "error": "Route not found" }` |
| 500 | Unexpected server error | `{ "error": "Internal server error" }` |

## Examples

```bash
# Create
curl -X POST http://localhost:4000/api/todos \
  -H "Content-Type: application/json" \
  -d '{"title":"Buy milk","priority":"high","dueDate":"2026-12-01"}'

# List active high-priority todos, soonest due first
curl "http://localhost:4000/api/todos?status=active&priority=high&sort=dueDate"

# Mark as completed
curl -X PATCH http://localhost:4000/api/todos/<id> \
  -H "Content-Type: application/json" \
  -d '{"completed":true}'

# Delete
curl -X DELETE http://localhost:4000/api/todos/<id>
```
